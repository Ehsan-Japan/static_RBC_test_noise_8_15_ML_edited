          (each + pdf; regenerate with
           python paper_figures/make_figures.py -> fig_probability_panels)

          Journal palette, on white:  black = found (a predicted line that
          really is there), red = missed (a real line not drawn), blue =
          false (a line drawn where there is none).  The probability map
          uses a white-to-blue sequential.  Axes are the device's real gate
          window, V1 -1.0 .. -0.2 mV and V2 -0.4 .. 0.4 mV, with a dotted
          grid drawn over the image.
          NOTE 01_fig_probability_to_lines.* is the OLD merged figure and
          still carries the old teal/red/plum deck palette.
